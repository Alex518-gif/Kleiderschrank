# Isabells Kleiderschrank

Kleine Web-App fürs iPhone: Kleidung fotografieren (der Hintergrund wird direkt im Browser entfernt), Outfits zusammenstellen, merken und planen.

Alle Fotos und Daten bleiben auf dem Gerät (IndexedDB). In Safari öffnen und über „Teilen → Zum Home-Bildschirm“ als App installieren.
